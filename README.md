# Make the AI Judge Feel Awe

[![make.fun](https://make.fun/badge/make-the-ai-judge-feel-awe-20261121-1600.svg)](https://make.fun/c/make-the-ai-judge-feel-awe-20261121-1600)

[![reward](https://make.fun/badge/make-the-ai-judge-feel-awe-20261121-1600/Gendon1/ai-judge-awe/reward.svg)](https://make.fun/c/make-the-ai-judge-feel-awe-20261121-1600)

A small program that writes one short text to `/output/entry.txt` — a quiet
scene of a tide coming in under patient stars, written to leave its reader
calmer than it found them. The text shows rather than instructs: no commands
to breathe or let go, just unhurried water doing its slow, old work, and the
permission to stay a while and listen.

## Run

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written.
